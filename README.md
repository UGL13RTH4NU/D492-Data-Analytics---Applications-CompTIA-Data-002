## About the deck

Built one module at a time from the **CompTIA CertMaster Perform** textbook content and lesson quizzes, cross-referenced with the [DA0-002 Exam Objectives](https://www.comptia.org/certifications/data) and the Sybex study guide. Cards are tagged hierarchically and organized into sub-decks so you can study any module — or the whole course — independently.

**Card style**
- Scenario-style fronts ("which is BEST" / "what should the analyst do") that mirror how the exam asks questions
- Backs explain the correct answer, why each distractor is wrong, and include memory hooks where helpful
- HTML formatted with color coding (green = correct, red = trap/wrong, blue = key term)
- Missed quiz questions I had got a red "MISSED" banner with notes on the specific trap that caused the wrong pick. Whenever you're going through the material and encounter your own misses you should edit the card accordingly.

## How to use it

1. Install [Anki](https://apps.ankiweb.net/) (no charge, desktop or Android mobile, but you should probably drop a donation to the folks that create and maintain Anki).
2. Download `D492_Data_Plus_002.apkg` from this repo.
3. In Anki: **File → Import** and select the file.
4. The deck and all sub-decks will appear under **D492 Data+ 002**. Study the parent deck to cycle through everything, or click into a specific module or the quiz sub-decks for focused review.

If you only care about a specific topic, the hierarchical tags (`D492::Domain2::Module06::TopicName`, `D492::Acronyms::Domain1::TopicName`, etc.) make it easy to filter with Anki's browser.

## About the exam

CompTIA Data+ DA0-002 is the v2 of the Data+ exam:

- **90 questions** in **90 minutes**, multiple-choice and performance-based
- Passing score: roughly **675 / 900** (~70 – 75%)
- Heavy emphasis on **scenario-based** questions ("given a scenario, which approach is BEST")
- Five domains: Data Concepts and Environments (20%), Data Acquisition and Preparation (22%), Data Analysis (24%), Visualization and Reporting (20%), Data Governance (14%)
